Simple Quiz Application

This project is developed using Python Flask and HTML. It allows students to answer five multiple-choice questions and view their final scores.

Technologies: Python, Flask, HTML, VS Code.

Features:

- Student name input.
- Multiple-choice questions.
- Automatic score calculation.
- Result display.

How to Run:

1. Install Flask using "pip install flask".
2. Run "python app.py".
3. Open "http://127.0.0.1:5000" in your browser.

Conclusion: This project helps us learn the basics of Flask, HTML forms, routing, and input validation.
